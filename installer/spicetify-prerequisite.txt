Spotify integration is optional and available only on Windows.

Spicetify must already be installed if you want to use myMusic from Spotify's right-click menus. myMusic does not install Spicetify.

If Spicetify is detected, Setup installs and enables only the myMusic extension. Existing themes, extensions, Marketplace, and custom apps are preserved.

Without Spicetify, myMusic still works as a standalone application.
